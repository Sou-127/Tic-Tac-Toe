# Tic-Tac-Toe
A simple and interactive **Tic-Tac-Toe game** built using **HTML, CSS and JavaScript**.

The game allows two players to play against each other by taking turns placing **X** and **O**.It automatically detects wins and draws and provides a restart option.

## Features
- Two-player gameplay
- Player X and player O turns
- Automatic winner detection
- Draw detection
- Prevents moves after the game ends
- Restart game functionality
- Simple and responsive interface
- Custom background and game styling

## Technologies used
- **HTML5** - Game structure
- **CSS3** - Styling and layout
- **JavaScript** - Game logic and DOM manipulation
